# Pull request 12: skip cached build-context uploads

## Summary

- Add `LookupContext` as an additive RPC keyed by a validated lowercase SHA-256 digest.
- Report only completion-marked cache entries as reusable.
- Allow an optimized sender to finish a cache-hit transfer with its metadata header.
- Preserve compatibility by draining streamed bodies from legacy senders.
- Regenerate the Go protobuf and gRPC bindings.

See the companion [issue handoff](ISSUE-11.md) and [pull request 12](https://github.com/stephenlclarke/container-builder-shim/pull/12).

## Compatibility and risk

The RPC is additive. Existing clients continue streaming the body and are drained as before. Optimized clients may omit the body only after the builder positively identifies a completed entry. Digest validation and completion-marker checks prevent path traversal and reuse of partial data.
